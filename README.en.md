# Tiny Deadline

A lightweight TinyManager deadline radar for upcoming and overdue work without a noisy calendar.

## Alpha capabilities

- Quick title + date capture
- Persian phrases such as today, tomorrow and weekday names
- English `today`, `tomorrow` and weekday names
- Standalone app and TinyManager module package
- Local-first storage
- Deadline completion
- Optional `projectId` and source linkage
- TypeScript declarations
- Domain tests and GitHub Actions CI

Persian display inside TinyManager is backed by **Webtanan Jalali Date Engine**.

Version: `0.1.0-alpha.1`
